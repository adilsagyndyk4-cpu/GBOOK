# schoolb2 — cookie + журнал посещений

## Что сделано
- `inc/cookie.inc.php` — счётчик посещений и дата последнего визита в куках.
- `inc/log.inc.php` — запись пути пользователя в `log/path.log` (формат `timestamp|page|referer`).
- `inc/view-log.inc.php` — вывод журнала списком (пункт меню «Журнал посещений»).
- `index.php` — подключение `PATH_LOG`, cookie/log до вывода HTML, блок приветствия, пункт меню.
- `inc/headers.inc.php` — короткий тег `<?` заменён на `<?php` (PHP 8.3), убрано предупреждение об `$_GET['id']`.

## Запуск
1. Положить папку `schoolb2` в `domains` (Open Server), домен `schoolb2.loc`, PHP 8.3.
2. Открыть `http://schoolb2.loc/` (или `http://localhost/schoolb2/`).
3. Обновлять [F5], ходить по пунктам меню, затем открыть «Журнал посещений».

## Проверка счётчика по [F5]
В `inc/cookie.inc.php` есть переключатель:
```php
define('COOKIE_ONCE_A_DAY', true);  // куки обновляются раз в день (по заданию)
```
Поставьте `false`, чтобы счётчик рос при каждом нажатии [F5], потом верните `true`.

Папка `log` должна быть доступна на запись.
